# Math & Shape Explorer 📐✨

A Python Turtle graphics project designed to demonstrate cross-curricular **STEAM (Science, Technology, Engineering, Arts, and Mathematics)** integration for primary school computer science students. 

This repository showcases how basic programming constructs (loops, functions, and parameters) can be used to reinforce core mathematical concepts such as geometry, polygon properties, and spatial reasoning.

---

## 🎯 Pedagogical Goals
- **Abstraction & Modularity:** Utilizing reusable functions rather than repetitive code 
- **Math Integration:** Bridging code loops with geometry—calculating exterior angles.
- **Spatial Reasoning:** Combining basic geometric primitives (squares, triangles, rectangles) to daily life objects like houses and traffic lights.

---

## 🚀 Features Included
1. **Dynamic Polygon Drawer:** Draws equilateral triangles, squares, pentagons, and hexagons based on user-defined parameters.
2. **Concentric Circles:** Demonstrates manual circle generation through angular iteration along with built-in functions.
3. **The "House" Composition:** Combines coordinates, line movements, and shapes to teach spatial positioning.
4. **Traffic Light Sequence:** Illustrates coordinate placement and visual state changes.
